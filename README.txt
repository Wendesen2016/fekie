Academic website package for Wondowosen Fekie

Files:
- index.html: website source for GitHub Pages
- revised_index.html: standalone local preview with portrait embedded
- wondowosen-portrait.jpg: profile portrait used by index.html
- Wendesen_Fekie_CV.pdf: original CV PDF supplied by the user
- Wendesen_Fekie_CV_all_pages.png: one PNG image containing all three CV pages

Website features include responsive navigation, research and career sections, thesis repository link, a CV dropdown with separate PDF/PNG view and download actions, clickable email with a copy button, reading progress indicator, current-section navigation highlighting, back-to-top control, and a footer with copyright and last-updated date. The thesis affiliation is listed as Department of Social Anthropology.

Keep index.html, the portrait, and both CV files in the same folder when publishing. The live website has not been changed or published.
